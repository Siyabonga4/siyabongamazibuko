WorkFlow AI Hub
Project Overview
WorkFlow AI Hub is an AI-powered productivity assistant that automates 3 common workplace tasks: writing emails, summarizing meetings, and planning daily tasks. Built for Week 2 of AI Skills Acceleration to demonstrate practical AI implementation and prompt engineering.

Features
Smart Email Generator: Creates professional emails in formal, friendly, or persuasive tone.
Meeting Notes Summarizer: Converts long meeting transcripts into summaries, action items, and deadlines.
AI Task Planner: Generates prioritized daily/weekly schedules from user goals.
Tools Used
Lovable AI: For UI/UX and dashboard layout
ChatGPT API: For AI-generated responses and prompt engineering - GitHub: Version control and deployment
Setup Instructions
Clone the repo
Add your OpenAI API key to .env
Run npm install and npm run dev
Open localhost:3000 to use the app
Responsible AI Disclaimer
AI-generated content may contain errors or bias. Always review outputs before sending to others. No sensitive personal data should be input into the app.
